# Materiały graficzne — analiza dachów obiektów kandydujących

Folder przeznaczony na zdjęcia satelitarne i ortofotomapy dachów szpitali
rozpatrywanych jako obiekt referencyjny (por. `00_Kandydaci_obiekt_referencyjny.md`).

## Konwencja nazewnictwa plików

```
[Miejscowosc]_[typ]_[opis].png

Przykłady:
Pyrzyce_satelita_widok_ogolny.png
Pyrzyce_satelita_dach_zblizenie.png
Pyrzyce_ortofoto_pomiar_powierzchni.png
Goleniow_satelita_widok_ogolny.png
Nowogard_satelita_widok_ogolny.png
```

## Wymagania dla zrzutów ekranu

Aby ocena była miarodajna, zrzut powinien zawierać:

1. **Widok z góry** (rzut pionowy, bez perspektywy 3D).
2. **Podziałkę / skalę** widoczną w rogu mapy — niezbędna do oszacowania powierzchni.
3. **Pełną bryłę obiektu** wraz z bezpośrednim otoczeniem (ocena zacienienia od sąsiednich budynków i drzew).
4. Opcjonalnie: zbliżenie na stropodach w celu identyfikacji infrastruktury technicznej
   (centrale wentylacyjne, wyrzutnie, świetliki, kominy, ewentualne lądowisko).

## Zalecane źródła

| Źródło | Zastosowanie |
|---|---|
| Google Maps / Google Earth | Szybki przegląd, zdjęcia satelitarne |
| **Geoportal.gov.pl** | Ortofotomapa o wysokiej rozdzielczości + **narzędzie pomiaru powierzchni** (rekomendowane) |
| BDOT10k / dane katastralne | Weryfikacja obrysu i powierzchni zabudowy |

Geoportal umożliwia bezpośredni pomiar powierzchni dachu w metrach kwadratowych,
co pozwala zweryfikować założenie 1000–1500 m² bez szacowania z podziałki.
